# Pizzeria LaBenza (VB.NET)

A pizza ordering app written by Benoît Lafrance in Visual Basic .NET (Windows Forms, Visual Studio 2015, .NET Framework 4.5.2) for a high school computer science class in January 2017.

## How it works

- **Order screen:** pick Small, Medium or Large, and any of four toppings (pepperoni, bacon, pineapple, peppers). Each topping you tick shows its picture.
- **Calculate Price + Add** prices the pizza: $10, $13 or $15 by size, plus $2 for the first topping and $0.50 for each one after.
- **Shopping Cart** shows the order number and the total with 13% tax.
- **Place Order** opens a confirmation screen that asks for your street address, city and postal code.
- **New Order** resets the order screen.

## Running it

Open `Pizzeria - Ben.sln` in Visual Studio and press Start. Newer versions of Visual Studio may offer to retarget the project to a newer .NET Framework, which is fine.

## Files

| File | Purpose |
| --- | --- |
| `Pizzeria - Ben.sln` | Visual Studio solution |
| `Pizzeria - Ben/Form1.vb` | Order screen and pricing |
| `Pizzeria - Ben/Form2.vb` | Shopping cart and tax |
| `Pizzeria - Ben/Form3.vb` | Address and order confirmation |
| `Pizzeria - Ben/Module1.vb` | Order details shared between the screens |
| `*.Designer.vb`, `*.resx` | Screen layouts generated by Visual Studio. `Form1.resx` holds the pizza and topping pictures |

## Known quirks, kept as written

- Every click of **Calculate Price + Add** counts as a new order number, even when re-pricing the same pizza.
- The cart only holds the last pizza priced.
- The cart fills in its total only the first time it opens, so after one order is placed, the next order's cart comes up empty.
